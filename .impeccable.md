## Design Context

### Users
Developers running Claude Code, Codex, and Cursor concurrently on macOS. They need quiet, glanceable status and fast access to the exact session requiring attention.

### Brand Personality
Native, focused, and lightly playful. Agent Island should feel like a small macOS system utility, with pixel-agent character only where it communicates live activity.

### Aesthetic Direction
A notch-native black overlay paired with system-adaptive settings and onboarding windows. Use cool Mac-like blue as the primary accent, restrained green/red status colors, compact typography, and no decorative gradients or glow-heavy AI styling.

### Design Principles
- Make urgent agent actions readable and operable without leaving the island.
- Follow the macOS light/dark appearance automatically.
- Keep status, model, mode, and host metadata glanceable.
- Preserve native-feeling controls, keyboard access, and reduced-motion support.
- **No wider than its content needs.** Supersedes the older "keep the overlay
  compact": the expanded panel measures its content and sizes to it, up to
  720px. A diff you can't read isn't compact, it's just small. Sizes come from
  the type tokens in `styles/tokens.css` so the text-size setting scales
  everything at once — never hard-code a px font size.
- Follow the system accessibility settings rather than offering our own
  switches: `prefers-reduced-motion`, `prefers-contrast`, and
  `prefers-reduced-transparency` are all honoured in CSS. Text size is the one
  exception, because macOS doesn't expose its setting to Chromium.
- Every animation stays on `transform` and `opacity` only. The overlay runs
  without hardware acceleration and composites over the menu bar all day, so
  anything that repaints (`filter`, `box-shadow`, gradient interpolation) is a
  cost the user pays continuously.

### Materials
Materials are not decoration. The expanded panel is *made of* glass on macOS 26
(a native sheet beneath the web content, `native/AgentIslandNative.swift` +
`main/glass.ts`), with a translucent CSS panel and one static specular rim as
the fallback tier. The notch band stays pure `#000` in every tier so it keeps
merging with the hardware notch. Nothing about the material animates in CSS.

## Decoration
Agent UI stays undecorated — no gradients or glows on rows, cards, or controls.
The one sanctioned exception is the weather scene, where the decoration *is* the
information: the animation communicates the actual condition. Keep it confined
there.
